# Changelog
This document provides an overview of changes between released versions of this specification.

## Release v1.0.1 (documentation clarifications only)
*   The `grouphint` tag definition in the NMOS Parameter Registers makes clearer that roles need to be unique only among resources of the same type in a group, so a Sender and a Receiver in the same group can have the same role
*   The `grouphint` tag definition in the NMOS Parameter Registers makes clearer that an empty array or an empty string in the tag indicates no group membership, and an empty first string indicates no Natural Group
*   Link to the current location of the `grouphint` tag definition and fix typos

## Release v1.0
*   Initial release
